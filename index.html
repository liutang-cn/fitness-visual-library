来源与使用

把“器械识别”和“动作示意”分开使用，避免把动作图误当成产品图。

1. 你提供的 GitHub 项目：动作层

hasaneyldrm/exercises-dataset 当前公开说明包含 1,324 条动作记录、器械字段、肌群字段、10 种语言说明，以及每条动作的 180×180 缩略图和 GIF。

它解决的是“这个动作叫什么、用什么器械、动作演示长什么样”，不是独立的器械产品白底图库。

在线打开动作筛选器 ↗下载完整 JSON ↗查看 GIF 目录 ↗

2. 器械图鉴：编辑层

本页的 63 张器械图是通用类型示意，适合做认知卡、加中文/英文标题、箭头和局部放大。要做品牌型号卡，应从厂家产品目录取图，并保留品牌与型号。

3. 你可以怎么编辑成自媒体素材

  1. 器械卡：保留一张无字图，另加“中文通用名 / English name / 常见别名”。
  2. 认知卡：从识别提示里挑一句，解释“看哪里能认出来”。
  3. 动作卡：从动作区下载 JPG 或 GIF，只写动作名称和所用器械，不把它写成专业教学。
  4. 发布前：把图片来源、品牌型号或数据集归属写进素材备注，方便以后复核。
